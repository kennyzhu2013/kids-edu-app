# 课程编码说明

Sprint 1 只用这一套编码。归档规划文里的历史表述不改。

## 学科

规划学科是 `CurriculumSubject`，不是产品课程馆的 `Subject`。`GET /api/subjects` 仍只返回 `lang` / `math` / `eng` / `life`。

| 码 | 名称 |
|---|---|
| ZH | 中文启蒙 |
| EN | 英语启蒙 |
| MA | 数学启蒙 |
| SC | 科学探索与认知 |
| HL | 健康与生活 |
| SE | 社交与情绪 |
| AR | 艺术与创造 |

## 数学专题

生活数学保持独立专题，编码 **MA09**。时间认知保持 **MA08**，不合并成「时间与生活数学」。

| 码 | 名称 |
|---|---|
| MA01 | 数字认知 |
| MA02 | 数量与数感 |
| MA03 | 数字运算 |
| MA04 | 图形认知 |
| MA05 | 规律排序 |
| MA06 | 分类比较 |
| MA07 | 空间认知 |
| MA08 | 时间认知 |
| MA09 | 生活数学 |

`math-life-04`（几点钟整点）只挂 MA08。`math-life` 其余四关挂 MA09。`math-starter` 按关跨多个数学专题，不另建一个和这些编码平行的「数感启蒙」专题。包名「数感启蒙」仍是 `Pack.title`。

因此数学是 9 个专题。中文、英语沿用规划分领域表里已经写过码的 8 个专题，科学、健康、社交、艺术按七个模块补齐专题骨架。库里的专题数多于「约 45」这个概数；45 是生活数学还没单列、中英文还没按已有编码表计算时的约数。

## 知识点

只建已经能对上现有关卡或游戏的知识点，外加两条没有关卡的骨架：

- `ZH02-001` 拼音声母初识。年龄段 A 写「不作为目标」。
- `MA03-001` 20以内加减初步。年龄段 A、B 都写「不作为目标」。

这两条不打到现有关卡上。前置用 `KnowledgeDependency`（`prerequisite` / `related` / `extension`），不用 `parentId`。`fromId` 是起点，`toId` 是被指向的知识点。例如 `MA01-002` prerequisite `MA01-001`，表示认识 6–10 以前置「认识 1–5」。

拼音用 `extension` 指向汉字，不做成年龄段 A 的必修前置。

## 内容上的 id

关卡和游戏 JSON 追加 `knowledgePointIds`。`math-starter` 每一关、每一步都有 id。其它关卡至少在关卡上有 id。游戏保留原来的 `knowledgeTags`。颜色配对挂中文和英语的颜色知识点，不挂艺术。

运行时校验以 Zod 为准。`content/schemas/level.schema.json` 同步加了可选字段，但这份 JSON Schema 仍然不会被加载。

## 数学试点计分

不建 `Question` 表。`math-starter` 的服务端用夹具里该步骤的 `answer` 或篮子对照客户端交来的选择。`tap` / `drag` / `sort` 决定星星。跟读只记「说对了 / 说错了 / 未作答」，不加减这次的服务端星星。其它课包仍接受原来的 `score` / `stars`。
